1. Writing maintanable and readable programs
In order to write readable and adaptable programs I used the CRUD python module, focusing on seperating the system responsablities into modular components. By isolating these operations into dedicated classes the app avoids any duplicated logic and becomes more streamlines and easy to understand at a glance.

The dashboard code didn't need to include raw databse logic because I used methods like read() to retrieve data. not only did this make the system more readable, but this made the system more adaptable since any changes to the database structure only needs to be updated once rather than throughout the whole application.

3. What do computer scientists do?
The main job of a computer scientist is to take data and turn that into useable information- to improve efficiency, accuracy, and enable more complex systems to be built. More than anything computer scientists are system designers, in the project I took data from animal shelters and visualised it in order to identify dogs that would be able to do their training. A program like this incredibly reduces the time required to sort through large datasets like these, and increases the accuracy of decisions, meaning for Grazioso Salvare: faster idenification, better allocation of resources, and the ability to even have larger datasets due to a more efficient way of working through them.
